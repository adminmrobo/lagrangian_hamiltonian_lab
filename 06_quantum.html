연산자가 된 해밀토니안

양자 세계에서는 에너지가 계단처럼 띄엄띄엄

원자료 ① The Hamiltonian Operator · @askwhyvalley (1·2·4번 칸)방법: H를 파동에 작용하는 연산자로일상: 기타 줄의 정해진 음

왜 이 방법을 쓰나

  1. 문제 — 원자 속 전자의 에너지는 아무 값이나 가질 수 없습니다.
  2. 앞 방의 한계 — 공 하나의 해밀토니안(숫자)으로는 "정해진 값만 된다"를 설명하지 못합니다.
  3. 해법 — H를 파동에 작용하는 연산자로 바꾸면, 정해진 값(고윳값)만 나옵니다.
쉽게 말하면 — 기타 줄은 줄 길이에 맞는 음만 납니다. 상자에 갇힌 전자도 상자에 맞는 에너지만 가집니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 슈뢰딩거 방정식은 이름부터 겁나요.

학교 수학으로 보면 — 삼각함수 sin, 거듭제곱

식 조각뜻
Ĥψ = Eψ연산자 H를 파동 ψ에 작용하면 숫자 E배가 된다(정해진 에너지)
ψₙ = √(2/L)·sin(nπx/L)상자 속 파동. n은 마디 수 + 1
Eₙ = n²π²ħ²/(2mL²)상자 속 에너지 계단
Eₙ = ħω(n + ½)용수철 계단(6번 방의 그릇)
숫자로 한 번 해 보기
1nm 상자 속 전자: 바닥 에너지 ≈ 0.376eV
n = 2 → 4배(1.50eV), n = 3 → 9배(3.38eV)
용수철은 계단 간격이 일정: ½, 1½, 2½ … (ħω 단위)
조수 계단이 n²으로 벌어지는 상자와, 같은 간격인 용수철이 다르네요.

일상으로 치면

피아노 건반처럼 정해진 음만 칠 수 있는 악기와 같습니다.

평균 에너지는 바닥보다 낮을 수 없다 — 변분 원리

파동 모양을 바꿔 가며 평균 에너지를 낮춘다 — 손실 줄이기와 같은 모양

원자료 ① The Hamiltonian Operator · @askwhyvalley (7번 칸)방법: 시험 파동의 손잡이를 돌려 ⟨H⟩ 최소일상: 열쇠 깎기

왜 이 방법을 쓰나

  1. 문제 — 큰 분자의 가장 낮은 에너지(바닥)를 알고 싶습니다.
  2. 앞 방의 한계 — 19번 방처럼 식을 정확히 푸는 것은 큰 분자에서 불가능합니다.
  3. 해법 — 시험 파동을 정해 평균 에너지 ⟨H⟩를 계산하고, 손잡이를 돌려 가장 낮게 만듭니다.
쉽게 말하면 — 열쇠를 조금씩 깎아 보며 자물쇠에 가장 잘 맞는 모양을 찾는 것과 같습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 ⟨H⟩는 왜 진짜 바닥보다 낮아질 수 없어요?

학교 수학으로 보면 — 분수함수, 산술·기하 평균(a + 1/a ≥ 2)

식 조각뜻
⟨H⟩ = ⟨ψ|Ĥ|ψ⟩파동 ψ일 때 평균 에너지(원자료 ① 7번 칸)
⟨H⟩ ≥ 바닥 에너지변분 원리 — 어떤 시험 파동도 바닥 아래로 못 감
⟨H⟩ = a/4 + 1/(4a)용수철, 넓이 손잡이 a인 종 모양 파동
숫자로 한 번 해 보기
a = 2 → ⟨H⟩ = 0.5 + 0.125 = 0.625
a = 1 → ⟨H⟩ = 0.5 = 진짜 바닥
a = 0.5 → ⟨H⟩ = 0.125 + 0.5 = 0.625
조수 손잡이 a가 모델의 가중치, ⟨H⟩가 손실이네요!

일상으로 치면

여러 열쇠를 깎아 볼수록 잘 맞지만, 원래 열쇠보다 더 잘 맞을 수는 없습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 스핀이 +1, −1이라는 게 조 나누기랑 같은 거예요?

학교 수학으로 보면 — 곱셈, 경우의 수

식 조각뜻
s = +1 또는 −1스핀(두 조 중 하나)
s₁·s₂같은 조면 +1(불편), 다른 조면 −1(편함)
+ s₁1번 사람은 −1 조를 선호
H = s₁s₂ + s₁이 문제의 에너지
숫자로 한 번 해 보기
(+1, +1): 1 + 1 = 2
(+1, −1): −1 + 1 = 0
(−1, +1): −1 − 1 = −2 ← 가장 낮음
(−1, −1): 1 − 1 = 0
조수 네 가지밖에 없으니 다 따져 봤지만, 사람이 100명이면 2¹⁰⁰가지군요.
