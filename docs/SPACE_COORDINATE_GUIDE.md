# 공간 좌표 해설 제작 지침서 (범용)

> version 1.0 · 2026-11-19 · 글 · 안상선 ((주)M-Robo 대표)
> 적용 스킬: 연구실 비전공자판(ai-lab-explainer-plain) · 분야: 1 인공지능(기본)
> 첫 적용: 힐베르트 공간 해설(이 저장소) — 적용 계획은 [PLAN_hilbert_space.md](PLAN_hilbert_space.md)
> 이 지침은 유클리드 공간, 힐베르트 공간, 벡터 공간, 임베딩 공간, 특성 공간처럼 **"데이터를 공간 위의 점·화살표로 보는" 모든 콘텐츠**에 다시 쓴다.

---

## 1. 목표
- 공간의 규칙(길이·각도·직각·그림자·조각 나누기)을 **고등학교 수학 용어까지만** 써서 설명한다.
- 각 규칙이 **인공지능·머신러닝의 어떤 계산**이 되는지 반드시 잇는다.
- 원자료(인포그래픽·교안)의 차트는 구도·색·기호를 살려 다시 그리고, 직접 움직이는 실험 패널로 바꾼다.

## 2. 독자와 눈높이
- 주 독자: 수학·AI를 처음 접하는 대학생과 직장인.
- 용어: 고등학교 수학 교과 용어까지만 본문에 쓴다(좌표평면, 공간좌표, 벡터, 내적, 정사영, 삼각함수, 수열의 극한, 급수, 피타고라스 정리).
- 그 밖의 용어는 아래 대조표의 쉬운 말로 바꾸고, 원어는 접는 약어 상자에만 둔다.
- 페이지 문장에 "고등학생 눈높이", "중학생도" 같은 말은 쓰지 않는다.

### 2-1. 용어 대조표 (계속 늘려 쓴다)
| 원어 | 본문에서 쓰는 말 |
|---|---|
| 유클리드 공간 ℝⁿ | 자와 각도기가 있는 n칸짜리 방 |
| 벡터 공간 | 더하고 늘릴 수 있는 방 |
| 내적(inner product) | 겹침 점수 — 같은 자리끼리 곱해서 더한 값 |
| 노름(norm) | 길이 |
| 거리(metric) | 두 점 사이 길이 |
| 직교(orthogonal) | 직각 — 서로 영향을 주지 않는 방향 |
| 코시 수열 | 점점 서로 가까워지는 수열 |
| 완비성(completeness) | 빈틈 없음 — 다가가는 목적지가 방 안에 있다 |
| 기저(basis) | 좌표를 읽는 자 세트 |
| 정규직교기저 | 길이 1이고 서로 직각인 자 세트 |
| 계수 | 그 조각이 들어 있는 양 |
| 사영(projection) | 그림자(정사영), 수선의 발 |
| 잔차(residual) | 빗나간 만큼(남은 오차) |
| 최소제곱 | 빗나간 거리의 제곱 합이 가장 작게 |
| 부분공간 | 방 안의 바닥(평면)·선 |
| 차원 | 칸 수 |
| 푸리에 급수 | 물결 조각으로 나누기 |
| 파스발 항등식 | 조각으로 나눠도 길이²의 합은 그대로(피타고라스 확장) |
| ℓ² / L² | 끝없는 목록 방 / 곡선 방 |
| 거의 모든 곳에서 같음 | 점 몇 개만 다르면 같은 것으로 본다 |
| 평균제곱 수렴 | 전체로 보면 가까워진다(점 하나하나는 아닐 수 있음) |
| 커널·RKHS | 닮음 점수표(커널)로 만든 방 |
| 임베딩 | 단어·사진을 점으로 놓기 |
| 특성 공간 | 데이터 열(키·몸무게…)을 축으로 삼은 방 |

## 3. 공간 사다리 (콘텐츠 순서의 뼈대)
앞 칸의 한계가 다음 칸의 이유가 되게 잇는다. 콘텐츠마다 필요한 칸만 골라 쓴다.

| 칸 | 공간 | 할 수 있는 것 | 한계 → 다음 칸의 이유 |
|---|---|---|---|
| 1 | 좌표평면·공간좌표 (2·3칸) | 점을 찍고 거리를 잰다 | 데이터 열이 3개를 넘는다 |
| 2 | 유클리드 공간 ℝⁿ (n칸) | 길이·각도·거리를 n칸에서 잰다 | 칸 수가 정해져 있어야 한다 — 곡선·소리는 못 담는다 |
| 3 | 벡터 공간 | 더하기·늘리기만 정해 둔 넓은 방 | 길이·각도가 없다 |
| 4 | 내적 공간 | 겹침 점수로 길이·각도를 되찾는다 | 반복 계산의 목적지가 방 밖일 수 있다 |
| 5 | 힐베르트 공간 | 끝없는 방에서도 길이·각도·그림자·극한이 모두 된다 | (정점) — 응용으로 |
| 6 | 응용 공간 | 임베딩 공간, 특성 공간, 커널 방(RKHS) | — |

### 3-1. 입구 방 규칙 (모든 공간 콘텐츠의 첫 칸)
본론의 공간이 무엇이든, 맨 앞에 **유클리드 공간 입구 방**을 둔다.
1. 무엇인가 — 자와 각도기가 있는 평범한 방(좌표평면 → 공간좌표 → n칸)
2. 왜 쓰나 — 점 사이 "얼마나 먼가·얼마나 닮았나"를 숫자 하나로
3. AI에서는 — KNN(비슷한 것 찾기), 회귀(예측선 긋기), 임베딩(단어를 점으로)
4. 한계 — 그 콘텐츠의 본론이 풀어 줄 한계
5. 다리 — 본론 첫 방으로
- 기본 예시: 시아(160cm, 50kg)와 모아(163cm, 54kg) 거리 = √(3²+4²) = 5
- 기본 실험: 칸 수 슬라이더(2 → 3 → 10 → 100 → 끝없이)

## 4. AI·머신러닝 연결표
| 공간 규칙 | 머신러닝에서는 | 쉬운 장면 |
|---|---|---|
| 점·화살표 | 데이터 한 행, 임베딩 | 고객 한 명 = 점 하나 |
| 더하기·늘리기 | 특성 섞기, 가중합 | 장바구니 합치기 |
| 겹침 점수(내적) | 코사인 유사도, 추천, 어텐션 점수 | 두 사람 취향표 비교 |
| 길이·거리 | KNN, 군집(K-means), 제곱 오차(MSE) | 지도에서 직선거리 |
| 직각 | 서로 상관없는 특성, 주성분 | 동서·남북 |
| 빈틈 없음(완비성) | 경사 하강이 수렴할 자리가 있다 | 1.4, 1.41, 1.414… → √2 |
| 자 세트(기저) | 원-핫 인코딩, PCA | 길 안내 |
| 그림자(사영) | 예측선 긋기(최소제곱), 평균 | 정오의 그림자, 키의 평균 |
| 물결 조각(푸리에) | 음성 인식, 위치 인코딩 | 이퀄라이저 막대 |
| 피타고라스 확장(파스발) | 압축, 설명 비율(PCA) | 용돈을 통장에 나눠도 합은 같다 |
| 닮음 점수표(커널) | SVM, 커널 방법 | 지도 없이 거리표만으로 길 찾기 |

## 6. 원자료 차트 다시 그리기 규칙
1. 구도·색·기호·축 이름을 원자료와 같게 SVG로 다시 그린다(이미지 붙여넣기 금지).
2. 손으로 움직일 요소를 하나만 정한다(끌기·슬라이더·켜고 끄기).
3. 움직일 때 바뀌는 숫자는 패널 아래 한 줄로 업무 말과 함께 보인다.
4. 원자료 출처를 각 칸 꼬리표와 바닥글에 밝힌다(예: 원자료 @eeanimation).
5. 원자료의 오류·기호 충돌은 검산 후 "원자료의 A를 이 페이지에서는 B로 바꿉니다"로 적는다.

## 8. 이야기 형식 — 방 탈출형 (이 계열 기본)
- 연구실 복도에 번호 붙은 방이 있고, 방마다 원자료 카드 한 장이 붙어 있다.
- 시아·모아가 실험 패널로 답을 맞혀 방을 통과한다.
- 편 짜임: **0편 오리엔테이션(선행 시리즈 복습) → 입구 방(유클리드) → 본론 방들 → 대결 → 아웃트로**.
- 0편은 "먼저 보고 오면 좋다"는 추천만 하고 관문으로 만들지 않는다 — 건너뛰기 버튼 필수, 0편만 읽어도 따라올 수 있게.
- 0편 카드는 요약 3줄 + 실험 1개 + 원편 링크. 원편 내용을 다시 쓰지 않는다.

## 9. 방(칸) 하나의 짜임
1. 방 제목 + 꼬리표(원자료 카드 번호·출처, "방법: …", "일상: …")
2. 왼쪽 「왜 이 방법을 쓰나」(문제 → 앞 방의 한계 → 해법 → 쉽게 말하면 한 줄) | 오른쪽 「조수 수식 상자」(조수 질문 → 학교 수학으로 보면 → 식 조각 표 → 숫자로 한 번 해 보기 → 조수 코멘트)
3. 일상으로 치면 | 머신러닝에서는
4. 방 대화 2~3줄(박사 질문 · 주판봇 확신 · 초파리 "이걸 눌러 봐" · 시아/모아 반응)
5. 실험 패널(원자료 차트) → 풀이 → 이 방의 한계
6. 코드 접기 상자(필요한 방만, 코드 한 줄 + 뜻 한 줄)
7. 확인 퀴즈 1문항

## 10. 문장 규칙
1. 동작 먼저, 전문용어는 괄호로(또는 접기 상자로).
2. 기호(θ, ‖x‖, ⟨x,y⟩)는 처음 나올 때 뜻을 앞에.
3. 본문에 코드·함수 이름 금지.
4. 숫자는 업무 말로.
5. 문장 25~60자, 한 단락 세 문장 안팎.
6. 콘텐츠에서 학술적 주장을 하지 않는다 — 원자료와 교과 내용을 쉽게 옮기는 데 집중.
